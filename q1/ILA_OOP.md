Encapsulation - You can split the problem into multiple separate items. It can make it easier for the code to be organized.

Abstraction - It hides the complicated part of the code in the problem it shows the specific part of the problem needed. It makes the code easier to understand.

Inheritance - You can make a simple template then pass it down to the instances. It makes coding easier and less repetitive.

Polymorphism - Lets the same process work for multiple objects. It makes the code more concise and a easier way to understand the process.
